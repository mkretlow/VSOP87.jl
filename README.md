# VSOP87.jl [![Build Status](https://github.com/mkretlow/VSOP87.jl/workflows/CI/badge.svg)](https://github.com/mkretlow/VSOP87.jl/actions) [![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](https://opensource.org/licenses/MIT)

Julia implementation of the planetary solutions VSOP87 by Bretagnon &amp; Francou.

Currently **VSOP87 version A** is implemented for the eight major planets:

- Heliocentric rectangular coordinates X, Y, Z in AU
- Referred to the dynamical ecliptic and equinox J2000
- Validity span: 2000 BC – 6000 AD, theoretical accuracy ±1″ over this span

## Installation

The package is not registered yet. Install it from GitHub:

```julia
using Pkg
Pkg.add(url="https://github.com/mkretlow/VSOP87.jl")
```

## Usage

The input is a Julian Date in Terrestrial Time (TT).

```julia
using VSOP87

VSOP87A(:Earth, 2451545.0)     # 2000 Jan 01.5 TT
# 3-element Vector{Float64}:
#  -0.17713545858741392
#   0.9672416236823157
#  -3.90003182454353e-6
```

Valid body symbols are `:Mercury`, `:Venus`, `:Earth`, `:Mars`, `:Jupiter`, `:Saturn`, `:Uranus`, and `:Neptune`.
Each planet also has its own exported function, e.g. `VSOP87A_Mars(jd_tt)`.
